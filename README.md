# 无障碍求职与手语翻译服务平台（前端原型）

面向听障人群的无障碍求职与手语翻译服务平台前端原型，采用“求职者—手语翻译志愿者—企业 HR”三端协同设计，覆盖登录注册、个人主页与简历、求职招聘（职位与企业详情、投递、约面试）、即时聊天、手语翻译服务工作台、视频翻译室、消息中心与助残就业资讯等模块。纯原生 HTML/CSS/JavaScript 实现，零依赖、无需构建。

## 三端协同

| 端 | 角色 | 核心页面 |
| --- | --- | --- |
| 用户端 | 听障求职者 | 首页、登录/注册/找回密码、个人主页与简历、求职招聘（职位详情、企业详情）、新闻资讯、聊天窗口 |
| 志愿者端 | 手语翻译志愿者 | 翻译工作台（待接单/进行中/历史记录）、视频翻译室、消息中心、个人主页、新闻资讯 |
| HR 端 | 企业招聘方 | 招聘首页、人才推荐、求职招聘、简历详情、约面试、企业主页、个人主页、聊天窗口 |

## 本地预览

项目为纯静态页面，无需安装依赖与构建：

1. 直接在浏览器中打开对应端的入口页面，例如 `用户端/首页/index.html`。
2. 建议使用 VS Code 的 Live Server 插件启动本地服务，避免相对路径与跨目录跳转受限（推荐端口 5501，编辑器配置不入库，可自行在本地添加）。

推荐入口：

- 用户端：`用户端/首页/index.html`
- 志愿者端：`志愿者端/翻译工作台/index.html`
- HR 端：`HR端/首页/index.html`

## 技术说明

- 原生 HTML5 + CSS3 + 原生 JavaScript，无框架、无包管理器。
- 图标使用 Font Awesome CDN（`cdnjs.cloudflare.com`），离线环境下图标会降级为占位符，页面布局与交互不受影响。
- 布局以 Flexbox / Grid 为主，页面间通过相对路径互相跳转，适配桌面与移动端宽度。
- 全部源文件采用 UTF-8 编码。
